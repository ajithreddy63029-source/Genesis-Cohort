### What I Learned

In this assignment, I learned how to retrieve data using SQL queries, filter duplicate records with `DISTINCT`, sort records using `ORDER BY`, limit the number of rows using `LIMIT`, and use aggregate functions like `COUNT()`, `SUM()`, `MIN()`, `MAX()`, and `AVG()` to analyze data. I also practiced executing SQL queries in Databricks Community Edition and uploading my work to GitHub.
